# v0.1.1: time picker, clean trip start, more activity types, 100+ destinations

Patch release from PR #38. Backward compatible: **no new environment variables, no migration.**

## Fixes
| | |
|---|---|
| ⏰ Time picker | The hour knob no longer covers its number, AM/PM and hour/minute buttons are 44px, and on a short phone the picker centres with the page dimmed instead of covering the field. A blank number-formatted cell no longer shows as `0:00`. |
| 🧙 New trip | "Add new itinerary" always opens on "Where". An unfinished draft is offered (Continue / Start fresh) instead of jumping to the Review step; drafts expire after a week. |

## Additions
- **Five new activity types:** Nature, Culture, Nightlife, Wellness, Adventure (11 in all). They match only after the original types, so existing trips keep their categories.
- **Ready for 100+ destinations:** the spreadsheet is read in chunks of 25 tabs (4 at a time), the header shows a "More" menu, and the phone drawer and home list have search, Show all and A-Z sections. About 150 countries get a flag and default currency automatically.

## Limits that still apply
- 2000 rows per trip tab, 1000 trips in `_trips`, 100 Pocket items per trip.
- The world map has about 60 pin locations.

## Upgrade and rollback
- Upgrade: deploy as usual. Smoke-test the preview with real data (ideally a sheet with many tabs): `npm run smoke -- <preview-url>`.
- Rollback: revert the merge commit.
