# v0.1.0: trip wizard, Pocket and a leaner itinerary flow

Released from PR #37. Backward compatible: **no new environment variables, no required migration.**

## Highlights
| | |
|---|---|
| 🎒 **Pocket tab** | One tab per trip replaces Tools and Prepare. Keep flights, stays, docs and notes in one place, with the checklist and prayer times below. Bookings are private (sign-in required) and flights/stays also appear on their itinerary day. |
| 🧙 **Trip wizard** | `/add` is now Where → When → Review, with a live day count and a draft restored on your device. |
| ✏️ **One sheet to add or edit a place** | Day chips, place, time and type up front; location, price and notes under "More details". Time can stay unset (`--:--`). |
| 🧭 **Floating phone tab bar** | Rounded dock with line icons and a filled pill on the current tab. |
| 🎨 **Theme in the profile menu** | The floating sun button is gone; guests get a theme button beside Sign in. |

## Fixes
- Editing an activity no longer shows an empty date, `46357` or `0.375` when the sheet stores dates and times as numbers.
- An edit can only move an activity to a day of the trip (checked in the form and on the server).
- No more invented 09:00 when a time is unset.
- Add place and Pocket sheets no longer float under the header on phones.

## Data changes (no action needed)
- New hidden worksheet `_pocket` (created on first use).
- `_trips` gains `start_date` and `end_date` (older sheets upgrade on first save).
- Old `/tools` and `/prepare` links redirect to `/pocket`. Checklist ticks on devices are kept.
- The spreadsheet's editors can read `_pocket`: do not store passport numbers.

## Known gaps
- No photo/PDF upload in Pocket (attach a link instead); no per-item "Only me" visibility.
- Hub countries (several states) show no booking cards on the merged itinerary.

## Upgrade and rollback
- Upgrade: deploy as usual; no steps. Smoke-test the preview first: `npm run smoke -- <preview-url>`, then create a trip, add a flight and a stay in Pocket, and edit an activity.
- Rollback: revert the merge commit. Older code ignores `_pocket` and the new `_trips` columns.
